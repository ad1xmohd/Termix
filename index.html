Termix

A project to stylise Termux with custom banners, login scripts, modern prompt, password protection, and more.

Features

  • Full customisation of Termux environment
  • Password protection/login script support
  • Modern prompt/banner themes
  • Customize the “$” prompt symbol
  • Welcome message or voice‑message support

Getting Started

Clone the repo and run the setup script:


# termux‑setup‑storage
pkg update && pkg upgrade && pkg install git -y
git clone https://github.com/IND‑GANG/Termix
cd Termix
chmod +x *
bash Termix.sh
